## 📰 Claude Code上线Channels，接入Telegram和Discord

> **分类**: 链上侦探  
> **时间**: 09:13  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据 1M AI News 监测，Anthropic 编程 Agent Claude Code 团队工程师 Thariq Shihipar 宣布推出 Channels 功能，用户可通过 Telegram 或 Discord Bot 远程控制运行中的 Claude Code 会话，在手机上直接向 AI 编程 Agent 发送指令并接收响应。

该功能以官方插件形式提供，基于 MCP 协议实现。用户在 Claude Code 中安装插件、配置 Bot Token 后，以 --channels 参数启动会话，Bot 即开始监听消息。用户在聊天应用中发送的消息经 MCP 服务器转发至 Claude Code 处理，响应通过 Bot 回复，期间 Bot 自动显示「正在输入」状态。

## 📰 谷歌AI Studio正式上线全栈vibe coding：Antigravity Agent自动接管数据库和登录，内部已构建数十万应用

> **分类**: 链上侦探  
> **时间**: 09:05  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据 1M AI News 监测，谷歌今日正式发布 Google AI Studio 全新 vibe coding 体验，由 Gemini 3.1 Pro 驱动，集成新推出的 Antigravity 编程 Agent 和 Firebase 后端，将 AI Studio 从原型工具升级为可构建生产级应用的全栈平台。昨日 AI Studio 产品负责人 Logan Kilpatrick 已预告此次发布，称团队历时 4 个月从零重构。

核心能力包括：

1. 实时多人体验：支持创建多人游戏、协作工作区等实时连接应用
2. 自动数据库与认证：Agent 主动检测应用是否需要数据库或登录系统，经用户批准后自动配置 Cloud Firestore 数据库和 Firebase Authentication（支持 Google 账号登录）
3. 第三方服务接入：用户可通过新增的 Secrets Manager 安全存储 API 密钥，接入支付处理器、Google Maps 等外部服务
4. 现代 Web 工具链：Agent 自动识别需求并安装 Framer Motion、Shadcn 等第三方库，新增 Next.js 框架支持（此前仅支持 React 和 Angular）
5. 跨设备断点续作：关闭浏览器后项目状态自动保存，可在任意设备恢复

谷歌透露，该体验过去数月已在内部构建了数十万个应用。后续将接入 Google Workspace（连接 Drive 和 Sheets），并支持一键将项目从 AI Studio 导出至 Google Antigravity 平台。
