## 📰 OpenClaw面临稳定性困境，英伟达字节腾讯等仍滞留3月旧版本

> **分类**: 链上侦探  
> **时间**: 10:41  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，《The Information》报道称，OpenClaw 频繁的软件更新正在制造稳定性问题。英伟达、字节跳动、腾讯等多家基于 OpenClaw 构建产品的大公司，目前仍在使用 3 月上半月的旧版本，担心升级会引发严重技术故障。OpenClaw 维护者已开始协助这些公司做迁移，部分公司过去一周开始逐步更新，但完整迁移预计仍需时间。

Steinberger 今年 2 月被 OpenAI 雇佣，但 OpenAI 给了他充足时间继续领导 OpenClaw 开发，他同时在为今年 2 月宣布的 OpenClaw 基金会募资。

维护者团队内部出现路线分歧。一方主张引入传统产品管理模式，包括可预期的更新周期、严格的质量保证和与企业用户的正式协调；另一方担心引入这些流程会压制创新和实验精神。上周 OpenClaw 搞了一个「无新功能」周，专注提升速度和稳定性。维护者之一、耶鲁大学神经科学博士生 Gustavo Madeira Santana 表示：「我们希望提高稳定性，确保用户不会因为更新而担惊受怕。」

Anthropic 的新计费规则也在加重用户负担。网络安全公司 Alice 联合创始人兼 CEO Noam Schwartz 称，在新规则下使用 Anthropic 模型配合 OpenClaw 等第三方工具，原本每月 $200 的订阅开销「可能变成每天 $200」。OpenClaw 正引导用户转向 OpenAI 的模型。竞品方面，Nous Research 的 Hermes 在近期 GitHub 贡献者数量上已超过 OpenClaw。NPM 数据显示，OpenClaw 的平均周下载量较 3 月中旬峰值下降约一半。

资金支持方面，腾讯已同意向 OpenClaw 基金会捐款。OpenAI 也提出捐款但被 Steinberger 拒绝，不过 OpenAI 协助了基金会的文书工作，并向维护者提供了 Codex 使用额度。GitHub 和 Convex 也为维护者提供了免费服务。

## 📰 Ideogram上线Custom Branded Models，上传图库训出品牌专属图像模型

> **分类**: 链上侦探  
> **时间**: 09:18  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，Ideogram 推出 Custom Branded Models，用户上传 15 到 100 张品牌素材，系统自动生成标注并完成训练，随后可批量生成风格一致的新图。训练完成后拿到 custom_model_uri，可直接接入已有的生成 API，无需管理 GPU 或基础设施。此前 Ideogram 只能用 Style Reference 上传最多 3 张参考图做风格提示，现在改为用整套图库训练独立模型。API 端也开放了完整的训练流程，支持创建数据集、上传图片、启动训练和批量生成。

据动察 Beating 监测，小米 Xiaomi MiMo 发布 V2.5 系列模型并开启公测，包含 MiMo-V2.5、V2.5-Pro、V2.5-TTS Series 和 V2.5-ASR 四个成员。V2.5-Pro 是该系列旗舰，定位长程复杂 Agent 任务，官方称其在通用 Agent 能力、复杂软件工程和长程任务上可与 Claude Opus 4.6、GPT-5.4 正面竞争。V2.5 为全模态 Agent 模型，同时处理图像、音频和视频，支持百万 token 上下文。
