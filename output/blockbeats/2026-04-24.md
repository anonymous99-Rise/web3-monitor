## 📰 Claude Managed Agents上线跨会话记忆，Rakuten用后首次通过错误降97%

> **分类**: 链上侦探  
> **时间**: 10:39  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，Anthropic 为 Claude Managed Agents（4 月 8 日公测的云端 agent 托管平台）新增内置记忆功能，公测开放。agent 可跨会话学习和积累经验，开发者无需自建记忆基础设施。

记忆以文件形式挂载在 agent 的文件系统上，Claude 直接用 bash 和代码执行能力读写，与处理其他文件一致。多个 agent 可共享同一记忆存储，支持权限分级：例如全组织记忆库设为只读，个人记忆库允许读写，多个 agent 并发操作同一存储不会互相覆盖。记忆可通过 API 导出和管理，所有变更带审计日志，可追溯到具体 agent 和会话，支持回滚和内容删除。

官方公布四个客户案例。Rakuten 的长时运行 agent 跨会话学习避免重复错误，首次通过错误减少 97%，成本降低 27%，延迟降低 34%。Wisedocs 在文档验证流水线中用跨会话记忆识别反复出现的文档问题，验证速度提升 30%。Netflix 的 agent 跨会话保留多轮对话中发现的洞察和人工纠正，不再需要手动更新 prompt 和 skills。Ando 用记忆捕捉每个组织的协作习惯，省去自建记忆基础设施的工作。

> **时间**: 08:29

据动察 Beating 监测，xAI 发布语音 agent 旗舰模型 grok-voice-think-fast-1.0，已通过 API 开放。该模型面向客服、电话销售等复杂多步骤工作流场景，能在后台推理且不增加响应延迟，原生支持 25 种以上语言。

xAI 称该模型与 Starlink 合作开发，Starlink 的电话销售和客服系统已在使用。xAI 公布的运营数据：电话销售中 20% 的咨询者当场购买 Starlink 服务；70% 的客服请求由 agent 自主解决，无需转人工；单个 agent 调用 28 个工具，覆盖数百个支持和销售流程，可自主执行硬件故障排查、更换和服务积分发放。

上代模型 grok-voice-fast-1.0 已标记弃用，官方建议迁移至新模型。
