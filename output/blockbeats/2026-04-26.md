## 📰 CocoIndex V1发布：AI agent数据只更新变化部分，pip install直接跑

> **分类**: 链上侦探  
> **时间**: 11:17  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，开源项目 CocoIndex 发布 V1，对引擎做了完整重写。CocoIndex 帮 AI agent 把代码库、文档、会议记录、PDF 等数据源转换成 agent 可用的结构化上下文，核心卖点是增量处理：一份文档改了一段，只有受影响的部分重新计算，其余跳过，源文件删除时对应的数据库记录也自动清理。

V1 有两个面向使用者的大改动。一是去掉了项目自己的配置语言，整条数据处理流程用普通 Python 函数写就行，可以直接打断点调试。引擎在后台自动追踪每个函数的输入和代码变化，只有真正变了的部分才重新执行。二是去掉了对 Postgres 数据库的强制依赖，`pip install cocoindex` 后可以直接运行，不再需要先搭数据库。底层引擎仍用 Rust 实现，Apache 2.0 协议。

数据可以输出到 Postgres、LanceDB、Neo4j、SQLite、Kafka、S3 等十余种目标。GitHub 仓库提供 20 余个现成示例，覆盖文本向量化、PDF 转换、代码索引、对话转知识图谱等场景。
