## 📰 Astro联合创始人开源Flue：给AI agent用的「Next.js」

> **分类**: 链上侦探  
> **时间**: 09:19  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，Web 框架 Astro 联合创始人 Fred K. Schott 开源 Flue，一个用 TypeScript 构建 AI agent 的框架，Apache-2.0 许可证。Claude Code、Codex 这类编程 agent 之所以能自主写代码、跑测试、提交修改，靠的不只是大模型，还有模型外面一整套调度层：沙箱环境、技能调用、会话记忆。Flue 把这套架构做成通用框架，让开发者用几十行 TypeScript 就能搭出类似能力的 agent。

Flue 内置虚拟沙箱，agent 无需容器就能执行命令、读写文件；需要完整 Linux 环境时可对接 Daytona 或 Cloudflare Containers。敏感密钥通过代理层隔离，agent 进程看不到。写完后一键打包，支持部署到 Node.js、Cloudflare Workers、GitHub Actions 等平台。

Schott 称 Flue「像 agent 的 Astro 或 Next.js」，不是又一个 SDK，而是完整框架。项目最初在 Astro 仓库内部开发，现独立开源，标注为实验阶段。

## 📰 OpenAI悄悄改隐私政策：免费用户被默认开启广告追踪

> **分类**: 链上侦探  
> **时间**: 09:18  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，OpenAI 更新美国隐私政策，正式将用户有限标识符（cookie ID、设备 ID）共享给营销合作伙伴，用于在第三方平台投放定向广告并追踪转化效果。《连线》实测发现，免费账户的营销隐私设置默认开启，付费账户则未默认开启。

隐私政策原本的「供应商和服务提供商」分类被改为「供应商、服务提供商和营销合作伙伴」，新增语言明确允许与非服务提供商性质的外部广告技术公司共享数据。OpenAI 此前承诺「绝不出售」用户数据，更新后的表述改为「不出售，但可能与营销合作伙伴共享有限数据用于定向广告」。OpenAI 发言人强调对话内容不与广告商共享。

《连线》还发现，更新当天「敏感个人数据」保障条款一度从政策中消失。OpenAI 回应称系错误，随后将类似表述补回到另一段落。

广告业务方面，OpenAI 2 月开始在美国 ChatGPT 输出底部测试广告，广告主最低投放门槛为 20 万美元，近期已将试点扩展至加拿大、澳大利亚和新西兰。合作的广告技术伙伴包括 StackAdapt 和 Criteo。与此同时，Sensor Tower 数据显示 ChatGPT 3 月卸载量同比增长 413%，4 月同比增长 132%。

据动察 Beating 监测，五角大楼宣布与 8 家科技公司达成协议，允许它们的 AI 工具和基础设施部署到美军秘密级（IL6）和绝密级（IL7）机密网络。新签约方包括 Nvidia、微软、AWS 和初创公司 Reflection AI，加上此前已签约的 xAI、OpenAI、谷歌，以及当天追加的甲骨文。

协议核心条款：所有公司同意五角大楼将其技术用于「任何合法用途」。Anthropic 不在名单中。此前 Claude 是五角大楼在机密环境中唯一使用的大模型，但 CEO Dario Amodei 拒绝接受这一标准，要求政府书面保证不用于大规模国内监控和致命性自主武器。五角大楼 2 月底将 Anthropic 列为供应链风险，特朗普随后禁止其参与所有政府合同，双方正在联邦法院打官司。国防部长 Hegseth 在国会称 Amodei 是「意识形态疯子」。

尽管五角大楼急于用 OpenAI 和谷歌替代 Anthropic，迁移过程已出现技术问题，情报分析师仍在用 Anthropic 旧模型完成日常工作。特朗普虽下令年中前停用 Anthropic，但 Mythos 在网络攻防方面能力突出，《纽约时报》称这一禁令几乎确定会被撤回。
