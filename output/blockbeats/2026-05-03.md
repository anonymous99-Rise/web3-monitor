## 📰 Codex CLI新增/goal：设目标和预算，agent自己循环跑到完成

> **分类**: 链上侦探  
> **时间**: 10:20  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，OpenAI 开源终端编程 agent Codex CLI 发布 v0.128.0，核心新功能是 /goal 持久目标循环。用户输入 /goal "目标描述" 后，Codex 每轮结束时自动判断目标是否完成，没完成就继续下一轮，直到目标达成或 token 预算耗尽。

目标状态持久化在本地 SQLite 中，重启后仍在，可随时 /goal pause 暂停、`/goal resume` 恢复、`/goal clear` 清除。模型侧只暴露三个工具：查看目标、创建目标、标记完成。暂停和预算调整只能用户操作。PR 描述中写到，`create_goal` 的 prompt 被刻意收紧，禁止模型在普通对话中擅自创建目标，必须用户显式输入 /goal 才能触发循环。整套功能由 Eric Traut 通过 6 个 PR 实现，覆盖持久化层、app-server API、模型工具、运行时续接和 TUI 交互。

同版本另一个方向性变化：`--full-auto` 被弃用，TUI 中已移除，CLI 保留一版弃用警告后将彻底删除。替代方案是权限配置文件（Permission Profiles），支持内置和自定义权限预设，比全权委托的 --full-auto 粒度更细。

其他变化包括新增 Agent Graph Store（抽象子 agent 父子拓扑，为远程存储铺路）、远程插件缓存、外部 agent 会话导入，以及内置 codex update 命令。

## 📰 Transformer做成纯硬件电路，不用GPU跑出5万tokens/秒

> **分类**: 链上侦探  
> **时间**: 10:02  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，多伦多大学电气与计算机工程本科生 Luthira Abeykoon 和 Krish Chhajer 把 Karpathy 的 MicroGPT（200 行纯 Python 实现的迷你 GPT，仅 4,192 个参数）用 SystemVerilog 完整搬进了 FPGA。没有 GPU，没有 PyTorch，没有 CPU 推理循环，transformer 的每一步都是硬件电路，生成速度超过 5 万 tokens/秒。项目叫 TALOS-V2（Tensor Accelerated Logic for On-Chip Systems），已在 GitHub 开源。

跑在 DE1-SoC 的 Cyclone V 上，一块教学级 Intel FPGA。权重用 Q4.12 定点格式存在片上 ROM 里。模型里反复出现的矩阵向量乘法被做成一个 16 通道脉动阵列（systolic array），Q/K/V 投影、MLP、LM head 共用这一个单元，轮流跑。

注意力是最难搬的部分。Python 里 attention 一行公式写完，到硬件要拆成八步：生成 Q/K/V、扫描点积、跟踪最大值、近似 exp、累加、除法、混合 V、投影回去。作者说，做这个项目不是为了跑大模型，而是想把 transformer 推理的每一步都变成看得见的硬件：存储器、计数器、状态机、查找表。

## 📰 OpenRouter上线响应缓存：相同请求零计费，延迟从秒级降到毫秒

> **分类**: 链上侦探  
> **时间**: 09:49  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，OpenRouter 推出响应缓存（Response Caching）功能，开发者在请求头中加入 X-OpenRouter-Cache: true 即可启用。首次调用正常走供应商计费，之后完全相同的请求直接返回缓存结果，不产生任何 token 费用。

缓存命中后响应时间在 80 到 300 毫秒之间，缓存查询本身平均 4 毫秒。作为对比，未缓存时 Gemini 2.5 Flash 平均约 1.3 秒，Kimi K2.6 约 4.6 秒，GPT-5.5 约 9.1 秒。

该功能与供应商自带的 prompt 缓存不同。prompt 缓存在消息前缀重复时减少 prompt 部分的成本，响应缓存则完全跳过供应商，从 OpenRouter 边缘缓存直接返回完整响应。文本、图片、音频、文档、工具调用均可缓存，覆盖 /chat/completions`、`/responses`、`/messages`、`/embeddings 四个端点。缓存按 API key 隔离，TTL 默认 5 分钟，可设为 1 秒到 24 小时。

OpenRouter 列举的典型场景包括 agent 工作流重试（失败后从头跑，已缓存步骤免费跳过）、LLM 测试套件反复执行，以及重复上下文的批量处理。

> **分类**: 链上侦探  
> **时间**: 09:47  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，开源个人 AI 助手 OpenClaw 发布 v2026.5.2，是一次大规模工程维护更新。核心变化是插件系统开始从 npm 向自建分发平台 ClawHub 迁移，同时修复了超过 200 个已知 issue。

插件迁移方面，OpenClaw 引入了 ClawPack 打包格式，插件安装和更新现在会携带版本化的 artifact 元数据。当前仍默认走 npm，ClawHub 仅在显式指定 clawhub: 前缀时启用，属于过渡期。外部插件已支持从 Git 仓库直接安装。ACPX 和 OpenTelemetry 诊断被拆成独立包，不再随核心安装。

性能方面，这个版本集中治理了多条热路径。插件工具描述符引入缓存，prompt 准备阶段不再重复加载插件运行时；session 列表接口改用轻量缓存索引，大 session 仓库不再卡顿；Gateway 启动时跳过非必要的认证覆盖层，缩短就绪延迟。

一个值得关注的 bug 修复：心跳调度器此前未正确处理进程退出事件的反馈回路，导致配置为每 30 分钟的心跳实际每 10 秒触发一次，事件循环延迟峰值超过 6 秒，Control UI 和 TUI 均无法正常响应。新版引入中心化冷却机制和每 agent 防洪护栏，限制非预期反馈环最多每 60 秒 5 次。

其他变化包括：xAI 提供商默认聊天模型升级为 Grok 4.3；SDK 新增 tools.invoke RPC 接口；支付凭据、API Key 等敏感字段的日志脱敏覆盖范围扩大；Discord、Telegram、Slack、WhatsApp、Signal 等消息渠道各有数十项修复。

## 📰 ChatGPT周活未到10亿，营收领先地位被超越，OpenAI CFO建议IPO推迟至2027

> **分类**: 链上侦探  
> **时间**: 10:44  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，OpenAI CFO Sarah Friar 私下建议将 IPO 推迟到 2027 年，理由是公司尚未达到上市公司的财务报告标准。CEO Altman 则希望在 2026 年四季度尽快上市。两人此前发表联合声明称在算力采购问题上「完全一致」，但多位知情人士仍证实了这一分歧的存在。

分歧背后是增长放缓。OpenAI 去年底设定 ChatGPT 10 亿周活用户目标，未能达成，至今未宣布突破这一里程碑。2025 年 12 月周活为 8 亿，2026 年 2 月升至 9 亿，增速在高基数上明显减速。Google Gemini 在消费端抢走份额，Anthropic 的 Claude Code 在开发者市场起量，OpenAI 今年初连续错过多个月度营收目标。年化营收约 250 亿美元，而 Anthropic 4 月已越过 300 亿美元，以约四分之一的训练成本反超 OpenAI 成为营收第一。

算力开支也在修正。Altman 去年 10 月在直播中展示一张写着 1.4 万亿美元的幻灯片，称这是 OpenAI 的新增算力承诺。Friar 随后向投资人私下澄清：实际计划是到 2030 年支出 6000 亿美元。近几个月她进一步警告管理层，如果营收增速跟不上，公司可能无法兑付未来的算力合同。

投行告诉 Anthropic 和 OpenAI，谁先上市谁就能定义这个新行业，先到者优先获得大量等待入场的资金。高盛预计将在 OpenAI IPO 中担任主承销商。OpenAI 高管已与交易所接触讨论上市计划，但尚未启动正式流程。

Friar 此前在 Square 有过类似经历：2015 年 IPO 市场低迷，投资者兴趣不足，定价当晚一度考虑撤回 IPO，最终以 9 美元每股、约 30 亿美元估值（前一轮估值的一半）上市，仅释放不到 10% 股份。三年后股价大涨。
