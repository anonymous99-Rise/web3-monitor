## 📰 Axios供应链攻击后遗症：明天起OpenAI旧版Mac应用全部失效

> **分类**: 链上侦探  
> **时间**: 14:33  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，OpenAI 的 macOS 签名证书将于明天（5 月 8 日）正式吊销。届时未更新的 ChatGPT Desktop、Codex、Codex CLI 和 Atlas 旧版将无法启动，也不再收到更新。用 Mac 版的现在就该更新，通过应用内更新或去 OpenAI 官网下载即可。

事情源于 3 月 31 日的一次 npm 供应链攻击。Axios，一个每周下载量超 7000 万的 JavaScript HTTP 库，被攻击者用窃取的维护者账号发布了两个恶意版本（1.14.1 和 0.30.4）。恶意版本注入了一个名为 plain-crypto-js 的假依赖，安装时自动下载远程访问木马（RAT），覆盖 macOS、Windows 和 Linux 三个平台。微软将这次攻击归因于朝鲜黑客组织 Sapphire Sleet。

OpenAI 的 GitHub Actions 工作流在构建 macOS 应用时自动拉取了恶意版本，而这个工作流能访问应用签名证书。OpenAI 分析认为证书大概率没被成功窃取，但按泄露处理，已轮换证书并与 Apple 合作封堵旧证书的公证通道。目前没有发现用户数据泄露、系统入侵或软件被篡改的证据，密码和 API key 也不受影响。

根因是工作流配置问题：引用依赖时用了浮动版本标签而非固定 commit hash，也没设 minimumReleaseAge（新包发布后的冷却期），导致恶意版本一上线就被自动拉入构建。

## 📰 Amp重写CLI砍掉手动上下文管理，5000条消息线程内存降70%

> **分类**: 链上侦探  
> **时间**: 13:16  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，Sourcegraph 旗下编程 agent Amp 开始分批上线重构版 CLI，代号 Neo。整套架构从头重写，核心变化是让 agent 自己管理上下文：上下文窗口用到 90% 时自动压缩摘要、开新窗口继续跑，取代原来需要用户手动触发的 Handoff 机制。本地启动的 agent 线程可从 ampcode.com 网页端实时操控，发消息、排队、取消都行。

同步正式发布 Plugin API。插件可以监听工具调用和 agent 生命周期事件、注册自定义工具和命令、弹出 UI 交互，也可以调用 AI 做分类判断。权限系统也改了：默认不再弹窗要求确认，原来的 --dangerously-allow-all 变成默认行为。官方的理由是前沿模型现在会写一次性脚本、链式调用 shell 命令，静态检查工具调用参数里有没有 rm -rf 已经防不住什么了。需要权限管控的团队可以通过 Plugin API 自建策略。

性能方面，用一个约 5000 条消息的线程实测，平均 CPU 占用从 84.1% 降到 17.4%，空闲内存从 1814MB 降到 540MB。消息排队也改成默认：agent 忙时发的消息自动排队，不再打断当前任务。

除 Handoff 外，Amp 还砍掉了文件变更回滚、技能管理命令、自定义主题和手动 bash 调用。官方说法是这些功能绑定的是 2025 年「模型需要更多看护」的使用方式，模型能力上来了就该退场。
