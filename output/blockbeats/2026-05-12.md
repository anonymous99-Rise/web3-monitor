OpenAI 今日在官网发布正式政策，宣布所有未经书面同意的股权转让均属无效，涵盖直接买卖、SPV（特殊目的工具）份额、代币化权益和远期合约。买卖双方拿不到任何经济价值，还可能违反美国证券法。早在 2025 年 8 月，OpenAI 就曾公开警告投资者警惕非授权 SPV 骗局，这次是正式立规矩。

封杀的背景是疯狂的二级市场。Anthropic 今年 2 月一级融资估值 3800 亿美元，二级市场却已飙到约 1 万亿美元。OpenAI 估值 8520 亿美元。两家公司均计划今年四季度 IPO，上市前把股权表上不受控的「野股东」清干净，既是合规需要，也是对定价权的争夺。

## 📰 告别满屏终端窗口：Claude Code上线多Agent中控台支持并行派单

> **分类**: 链上侦探  
> **时间**: 08:36  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，Anthropic 为其命令行工具 Claude Code 推出 Agent View。这是一个内置的任务面板，允许开发者在同一个终端窗口里调度、后台挂起和统一管理多个并行的 AI 代理。

过去让多个代理同时干活，需要开一堆终端标签页或 tmux 窗口。现在，开发者输入 claude --bg [task] 就能直接派一个新 Agent 去后台干活，或者用 /bg 指令把当前会话推到后台。

按下左方向键或输入 `claude agents`，终端会切出全局列表。每行展示一个任务的当前状态、最后一次回复和闲置时间。如果有的代理卡住了在等指令，开发者可以在不切入完整会话的情况下，直接在面板里原地回复。

这种并发模式极大地释放了个人开发者的产能。开发者可以一次性派发多个重构或修 Bug 的任务，然后回到列表里统一「批阅」它们生成的代码提交（PR），而不用死守着单个任务等输出。目前该功能已向 Pro 及以上付费计划和 API 用户开放研究预览。

> **时间**: 08:19
