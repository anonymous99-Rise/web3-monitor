针对这些问题，Mavis 采用代码状态机而非 prompt 编排来驱动协作。团队设三类角色：Owner 负责任务拆解与调度，Worker 专注执行，Verifier 独立验收。其中 Verifier 与 Worker 形成对抗机制，各角色上下文严格隔离，仅通过结构化摘要通信。MiniMax 在文中坦承，多 Agent 协作会引入额外的交接与聚合成本，但对于链路长、风险高的任务，这种结构化开销换来的是交付结果的确定性。

## 📰 何恺明团队ELF：语言扩散模型终于跑通

> **分类**: 链上侦探  
> **时间**: 12:43  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，MIT 何恺明团队发布语言扩散模型 ELF（Embedded Language Flows）。它没有沿用 GPT 式的自回归「预测下一个 token」路线，而是把文本生成放进连续 embedding 空间里完成，直到最后一步才转换回离散 token。

扩散模型在图像生成里已经成熟，但放到文本上一直很别扭：图像天然是连续信号，语言却由离散 token 组成。此前不少连续扩散文本模型，要么在生成轨迹中反复引入 token 级监督，要么需要额外独立解码器。ELF 的做法更干净：大部分步骤只在连续向量空间里去噪，最终一步再用共享权重网络完成离散化。

实验结果也有冲击力。在 OpenWebText 无条件生成评测中，105M 参数的 ELF-B 用 32 步采样达到约 24.1 的 Gen. PPL，优于多种离散和连续扩散语言模型基线。更关键的是，ELF-B 只用了约 45B 训练 token，而对比方法通常超过 500B，训练 token 少了约一个数量级。这个结果至少说明，连续扩散路线在语言建模里并没有被「语言离散性」堵死，之前的问题更可能出在建模接口和采样设计上。

李彦宏由此提出了一个新指标 DAA（Daily Active Agents，日活智能体数），对标移动互联网时代的 DAU（日活用户数）。他的逻辑是：当一个人拥有多个智能体、一个企业拥有成百上千个智能体，总量必然远超人口基数的 DAU。目前全球 DAU 最高的公司是 Meta，超过 34 亿；李彦宏认为未来全球 DAA 很容易超过 100 亿。「有多少 Agent 在给人类干活并交付结果，这比无谓的 Token 消耗更接近价值，也更接近本质。」

李彦宏还宣称 AI 正在催生「超级个体」。以前最小生产力单元是团队，现在变成了一个人加一支智能体编队。组织层面，每个管理者可以从管 10 人扩展到管 30-50 人，管理的核心功能从监督指挥变成一个词：对齐，即确认他在做对的事。
