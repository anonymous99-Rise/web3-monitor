## 📰 Nous Research发布Hermes Desktop：推出多平台原生智能体控制台

> **分类**: 链上侦探  
> **时间**: 12:06  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，Nous Research 宣布推出开源智能体 Hermes Agent 的原生桌面客户端 Hermes Desktop 公开预览版，支持 macOS、Windows 和 Linux 系统。该客户端旨在将先前以命令行（CLI）为主的 Hermes Agent 升级为更易用的图形界面（GUI）控制台，以便用户直观管理和运行这一具有自我提升（self-improving）能力的 AI 智能体系统。

在架构设计上，Hermes Desktop 采用主机直连架构（Host-first Architecture）。客户端通过本地文件系统或 SSH 隧道直接连接到 Hermes Agent 的宿主机环境，共享同一个底层「数据源」（包括 state.db 会话数据库、技能库及记忆目录）。这使得 Desktop 客户端与 CLI 终端、Web 看板及后台服务保持完全的状态同步，用户在任何一端所做的配置或对话修改都会即时互通，避免了状态漂移。

在功能特性方面，Hermes Desktop (当前版本 v0.15.2) 提供了完整的智能体控制中心：
• 渠道与交互：拥有 Chat-first 的对话界面，支持在侧边栏查看项目目录，并原生配置包括 Telegram、Discord、Slack、WhatsApp、Signal、Email 等在内的 15+ 种通讯平台网关。
• 记忆与技能系统：提供可视化面板用于查阅和直接编辑智能体的长期记忆（如 user.md 和 memory.md），并支持检索和管理智能体在任务中自动生成的技能库。
• 任务调度与安全沙箱：内置自然语言 Cron 定时调度，用于无人值守的自动化任务（如报告生成、自动备份）。此外，平台支持运行拥有独立上下文的子智能体（subagents），并提供本地、Docker、SSH、Singularity、Modal 等五种沙箱后端以实现容器加固，在 Windows 平台还进一步集成了微软执行容器（MXC）与 OpenShell 隔离技术。

用户可直接通过官方渠道下载安装包，或在已有 Hermes 终端中运行 hermes desktop 直接唤起。该项目完全开源，采用 MIT 许可协议。

## 📰 LangChain给Agent加上自动质检员，做不完就退回重改

> **分类**: 链上侦探  
> **时间**: 17:44  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，LangChain 发布 Deep Agents 新组件 RubricMiddleware，用来让 AI Agent 按预设标准检查并修改自己的输出。开发者可以先写清楚任务的「完成标准」，比如代码要通过测试、报告要覆盖指定章节、回答不能出现禁用内容。Agent 每次准备交付结果时，系统都会调用一个评审模型逐项检查；只要没达标，反馈就会返回给原 Agent 继续修改，直到通过检查或达到迭代上限。

这套机制解决的是 Agent 执行长任务时常见的「差最后一步」问题。很多 Agent 不是完全不会做，而是容易漏掉格式、测试、引用、章节等硬性要求。RubricMiddleware 相当于在任务链路里加了一个自动质检员，让 Agent 知道什么才算真正完成，而不是只生成一个看起来差不多的答案。

LangChain 文档也明确写到，这种方式最适合有清晰验收标准的任务，例如俳句音节是否正确、代码重构后测试是否通过、报告是否包含所有必需部分。对普通用户来说，它的价值不在于让 Agent 更会聊天，而是让 Agent 更像一个能按 checklist 交活的执行者。
