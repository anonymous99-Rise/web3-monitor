> **分类**: 链上侦探  
> **时间**: 12:22  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，谷歌研究部门与谷歌云合作推出 Agentic RAG 架构，并已在 Gemini Enterprise Agent Platform 平台开启公测。与传统的单步检索增强生成 Vanilla RAG 相比，新架构通过多智能体协同和质量控制机制，在事实性数据集上的准确率提升了高达 34%。

在新架构的工作流中，Orchestrator 负责评估复杂请求，Planner Agent 规划跨越多个数据库的搜索路径，Query Rewriter 将模糊提问拆解并重构为多个精准检索词，Search Fanout Agent 随后在各数据源并发执行搜索。

新架构最核心的改进是引入 Sufficient Context Agent 作为质量控制智能体，构建了「检索、评估、定向补充、再评估」的闭环迭代机制。在生成回答前，质量控制智能体不仅审查检索到的文本片段，还会对照用户提问评估中间草稿的匹配度。一旦判定信息不完整，系统不会直接输出残缺或带有虚假幻觉的答案，而是指出具体的数据缺口并生成反馈日志，指导 Query Rewriter 重构更具体的关键词进行定向二次检索，直至找齐所有缺失事实，最后由 Synthesis Agent 整合出完整答案。

在针对多源多步查询的 FramesQA 数据集测试中，结果显示，即使在需要跨越 4 个不同数据库进行检索的跨库场景下，谷歌的 Agentic RAG 依然实现了 90.1% 的准确率，几乎与单数据库检索的准确率持平。同时，双端运行的平均延迟差距保持在 3% 以内。
