> **时间**: 14:03  
> **来源**: [blockbeats](https://www.theblockbeats.info/inclusionid/?target=https%3A%2F%2Ft.me%2FOneMillion_AI)

据动察 Beating 监测，开源 AI 智能体开发框架 OpenClaw 发布 v2026.6.5 版本。作为采用全新按月修补命名法（「YYYY.M.PATCH」）的首个版本，新版主要围绕 LLM 推理模型适配、底层存储去碎片化以及插件生态稳定性进行了深度优化。

在模型交互与边界防御方面，针对长思考模型在即时通讯平台中的「内省泄露」痛点，QQBot 适配器新增自动剥离输出流中「thinking」标签的功能。同时，为解决 MCP（模型上下文协议）工具返回音频、资源链接等富媒体内容导致 Anthropic 等 API 报错的问题，新版在 materialize（实体化）边界引入强制转换机制，将非纯文本/图像的块安全序列化，避免触发「Anthropic 400 Bad Request」报错。此外，优化了流式会话启动逻辑，使得 prompt 缓存过期等预生成错误能正确触发恢复重试。

底层架构上，新版将 Matrix 同步加密、Memory-Wiki 导入、沙盒注册表等多处 ad hoc 运行状态文件统一收拢至 SQLite 数据库中。考虑到数据安全性，团队主动推迟了会话元数据（session-metadata）向 SQLite 的迁移，继续沿用稳定的 JSON 格式。

生态方面，ClawHub 技能现在支持通过 GitHub 仓库直接下载 pinned commit 部署，并通过重构文件监听器机制解决了大规模技能树下极易耗尽系统 Watcher 限制的瓶颈。
